# Page Turners

## Description
Book Haven is an online bookstore designed to connect readers with a wide variety of books. Users can browse, purchase, and review their favorite titles, as well as make donations to literacy programs. The platform provides a seamless and user-friendly experience, allowing book lovers to find their next great read.

## Features

User Authentication: Secure sign-up and login using JWT.
Book Browsing: View, search, and filter a comprehensive catalog of books by genre or title.
Reviews and Ratings: Users can leave reviews and ratings for books, helping others make informed choices.
Responsive Design: Fully functional on both mobile and desktop devices.

## Technologies Used

    Front End: React, Apollo Client
    Back End: Node.js, Express.js, GraphQL, Apollo Server
    Database: MongoDB with Mongoose ODM
    Styling: Styled-components or Ant Design

## Getting Started

### Prerequisites

    Node.js
    MongoDB
    Git

## Installation

### 1. Clone the Repository:

    git clone https://github.com/yourusername/book-haven.git
    cd page-turner

### 2. Install Dependencies: For the server:

    cd server
    npm install

### For the client:

    cd client
    npm install

### 3. Set Up Environment Variables: Create a .env file in the server directory and add your MongoDB URI and Stripe secret key:

    MONGODB_URI=mongodb://localhost:27017/page-turners
    JWT_SECRET=your_jwt_secret

### 4. Run the Application: Start the server:

    bash
    Copy code
    cd server
    npm start
    
### Start the client:

    bash
    Copy code
    cd client
    npm start

## Usage

Navigate to http://localhost:3000 to access the application.
Users can create an account or log in to start browsing books.
Browse through categories, search for specific titles, and leave reviews for books.
